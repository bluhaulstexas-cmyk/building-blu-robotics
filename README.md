## What we are building

Our first project is **TANK-001 / AI Tank with Tom**: a learning platform for printed mechanical parts, motors, electronics, local control and measured testing. Later ideas include cooperative ground robots, a shared mission board, mesh communications and supported drone integration. These are plans, not released capabilities.

This repository is a public build journal. It does not contain Binder Kernel source code, private invention disclosures, credentials, operational network configuration or a functioning robot-control service. It is separate from the private Binder repositories.

## Reading the status

An idea is not a selected design. A shopping list is not owned inventory. A drawing is not a fit test. A simulation is not a physical result. Each published build log should state its setup, observed result, remaining limits and next question. We will link released downloads here as they are reviewed.
