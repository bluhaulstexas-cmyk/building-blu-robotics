## Our working CAD collection

The private project archive combines original Avtanski files, a track-wheel test layout, a packaging study and separate COSGC reference designs. They are different sources and must not be presented as one original Building Blu design.

Only the verified original Avtanski ZIP above is released from the working collection. All other files are pending a per-file provenance, license and contents check. The complete backup ZIP is not a public release. COSGC motor-top, motor-bottom and motor-gear references are not cleared for redistribution by this journal. A test layout is not proof of print readiness, fit or completed construction.

For now, the original creator's public download above lets readers follow the mechanical starting point without exposing private project archives.
