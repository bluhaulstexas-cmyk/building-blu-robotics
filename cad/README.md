Use the creator's download link for the original files. This repository does not rehost them yet. Credit Alex Avtanski, link the original and license, preserve supplied notices and identify modifications when redistributing adapted files. Building Blu is not endorsed by the source creator.

The source design is a starting point. It does not establish fit for our selected motors, controllers or printer settings.

## Our working CAD collection

The private project archive combines original Avtanski files, a track-wheel test layout, a packaging study and separate COSGC reference designs. They are different sources and must not be presented as one original Building Blu design.

Public downloads from the working collection are pending a per-file provenance, license and contents check. The complete backup ZIP is not a public release. COSGC motor-top, motor-bottom and motor-gear references are not cleared for redistribution by this journal. A test layout is not proof of print readiness, fit or completed construction.

For now, the original creator's public download above lets readers follow the mechanical starting point without exposing private project archives.
